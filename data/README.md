# Տվյալների տեղադրում

Մուտքային տեսանյութերն ու ուսուցման dataset-ները պահեք տեղային կամ առանձին
տվյալների պահեստում․ մեծ տվյալները Git պահոցում չեն ներառվում։

Այս նախագծի EDA/ուսուցման համար օգտագործվում է Roboflow-ի
`football-players-detection` v1 YOLOv5 export-ը։ Պահանջվող կառուցվածքը՝

```text
<dataset-root>/
├── data.yaml
├── train/
│   ├── images/
│   └── labels/
├── valid/
│   ├── images/
│   └── labels/
└── test/
    ├── images/
    └── labels/
```

Նոթբուքի կամ ուսուցման հրամանին տվեք dataset-ի իրական ճանապարհը։ Դասերի YAML-ի
հարաբերական split ճանապարհները կարող են հին լինել․ գործիքները dataset root-ից
ստեղծում են ուղղված, ժամանակավոր Ultralytics YAML՝ առանց սկզբնական տվյալները
փոփոխելու։
